
MotivationApp

![image](https://github.com/user-attachments/assets/6415f33a-afca-4667-bdbc-922edc095cc1)


O aplicativo foi desenvolvido para fornecer ao usuário frases motivacionais de acordo com o tema escolhido. Quem hoje não precisa de uma motivaçãozinha ? :D

O usuário poderá inserir o nome na pagina inicial e escolher o tema da frase que será gerada. 

Foram utilizados conceitos de binding,sharedPreference, clean code e separação de responsabilidades de acordo com as boas práticas de programação.
